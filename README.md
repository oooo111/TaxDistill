# TaxDistill

**TaxDistill** is a tool for metagenomic classification and label correction. It leverages initial taxonomic labels, contig abundance data, and GenomeOcean references to improve classification accuracy.

## Parameters

| Parameter | Description |
|-----------|-------------|
| `--outdir` | Output directory for results |
| `--fasta` | Assembled contigs file in FASTA format |
| `--abundance_tsv` | Abundance file, typically containing coverage information for each contig |
| `--taxonomy` | Initial taxonomic labels generated by a classifier |
| `--genomeocean` | GenomeOcean dataset to use, e.g., `GenomeOcean/100M` |
| `--kd_alpha` | Knowledge distillation weight (range: 0–1) |
| `--kd_temp` | Knowledge distillation temperature |
| `-pt` | Number of parallel threads |
| `--cuda` | Use GPU for computation |
